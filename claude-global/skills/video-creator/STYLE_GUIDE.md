# 技术图风格指南

## 核心视觉基调：拟真白板手绘风 (Digital Whiteboard Aesthetic)

本风格模拟真实的白板/纸张教学场景，营造头脑风暴和现场教学氛围。

---

## 一、背景与介质

| 要素 | 规范 |
|------|------|
| 背景色 | 略带灰度的白色 (#F5F5F5 ~ #FAFAFA) |
| 纹理 | 白板或纸张肌理，画面干净但保留轻微纹理 |
| 氛围 | 头脑风暴、现场教学 |

---

## 二、线条风格

### 有机线条 (Organic Lines)
- ✅ 轻微抖动
- ✅ 粗细不均
- ✅ 明显马克笔笔触
- ❌ 完美几何形状
- ❌ 机械精确线条

### 图标风格
- 极简涂鸦式
- 火柴人表示人物
- 灯泡表示想法
- 齿轮表示系统/流程
- 文档图标表示代码/文件
- 强调概念传达效率

---

## 三、功能主义色彩体系

| 颜色 | 色值 | 用途 |
|------|------|------|
| 墨黑 | #1A1A1A | 框架、文字、逻辑连线 |
| 科技蓝 | #2196F3 | AI/智能化/数据流/箭头 |
| 警示红 | #F44336 | 旧模式、错误、限制、打叉 |
| 验证绿 | #4CAF50 | 成功、最终代码、打勾 |

### 色彩使用原则
- 墨黑为主色，占 60%
- 蓝色为引导色，占 25%
- 红/绿为强调色，占 15%

---

## 四、排版与字体

### 字体混合规则
| 场景 | 字体类型 | 示例 |
|------|----------|------|
| 标题 | 手写体 | 大号加粗 |
| 注释/说明 | 手写体 | 正常大小 |
| 代码块 | 等宽体 | 等宽字体 |

### 层级规范
- 一级标题：大号 + 加粗 + 下划线
- 二级标题：中号 + 加粗
- 正文/注释：正常大小
- 代码：等宽体 + 框线

---

## 五、叙事性构图逻辑

### 对比构图
```
┌─────────────────┬─────────────────┐
│    传统模式      │    AI原生模式    │
│    (左侧)       │     (右侧)       │
│   红色元素较多   │   蓝/绿元素较多  │
└─────────────────┴─────────────────┘
```

或上下对比：
```
┌─────────────────────────────────┐
│           传统模式 (上)          │
│          红色元素较多            │
├─────────────────────────────────┤
│          AI原生模式 (下)         │
│         蓝/绿元素较多            │
└─────────────────────────────────┘
```

### 流程引导
- 使用**蓝色粗箭头**引导视觉流程
- 信息模块化，用连线展示交互关系
- 从左到右或从上到下的阅读顺序

---

## 六、情感化设计细节

### AI 思考/生成效果
- 放射线表示能量/智能
- 动态线条表示运动/处理
- 光晕效果表示发光/活跃

### AI 拟人化
- AI 形象具备主动性
- 表现观察、指挥、理解等行为
- 可用简笔机器人或大脑图标

---

## 七、语言要求（强制）

| 规则 | 说明 |
|------|------|
| ✅ 简体中文 | 所有文字必须使用简体中文 |
| ❌ 英文 | 禁止任何英文单词 |
| ❌ 繁体中文 | 禁止繁体字 |
| ❌ 其他语言 | 禁止日文、韩文等 |

**适用范围：**
- 标题
- 标签
- 注释
- 说明文字
- 代码注释（如有）

---

## 八、Prompt 模板

### 基础模板

```
生成一张白板手绘风格的技术插图。

主题：[填写具体主题]

内容要求：
[描述需要展示的具体内容]

风格规范：
- 背景：白板/纸张纹理，略带灰度的白色
- 线条：马克笔手绘风格，轻微抖动，粗细不均
- 图标：极简涂鸦风格（火柴人、灯泡、齿轮、文档等）
- 色彩：墨黑(框架文字)、科技蓝(AI元素箭头)、警示红(旧模式错误)、验证绿(成功打勾)
- 构图：左右对比或上下对比，展示传统vs AI模式差异
- 箭头：蓝色粗箭头引导流程
- 文字：所有文字必须是简体中文，禁止任何英文

尺寸：800x600像素
```

### 示例 Prompt

```
生成一张白板手绘风格的技术插图。

主题：AI编程助手工作流程

内容要求：
展示程序员使用AI助手(如Cursor)编写代码的流程对比。
左侧展示传统模式：程序员手动查文档、写代码、调试（用红色标注痛点）
右侧展示AI模式：程序员描述需求，AI生成代码，一键部署（用蓝色和绿色标注优势）

风格规范：
- 背景：白板/纸张纹理，略带灰度的白色
- 线条：马克笔手绘风格，轻微抖动，粗细不均
- 图标：火柴人程序员、电脑屏幕、灯泡、齿轮、文档图标
- 色彩：墨黑(框架)、科技蓝(AI元素)、警示红(传统痛点)、验证绿(AI优势)
- 构图：左右对比，中间用蓝色大箭头连接
- 文字：所有文字必须是简体中文，包括"传统模式"、"AI模式"、"效率提升"等标注

尺寸：800x600像素
```
