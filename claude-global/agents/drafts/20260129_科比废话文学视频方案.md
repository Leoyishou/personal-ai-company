## 核心创意

### 什么是"科比废话文学"

网络流行梗,模仿科比·布莱恩特(Kobe Bryant)的名言风格:
- 看似很有道理,实则等于没说
- 正确的废话 + 逻辑闭环
- "你知道xxx吗?我xxx"句式

**经典案例**:
- "当你放弃的时候,就是比赛结束的时候"
- "你见过凌晨四点的洛杉矶吗?因为那时候我在训练"

### 过年场景适配

结合春节回家常见的烦人问题,用科比废话文学回应:

| 烦人问题 | 科比式回应 |
|---------|-----------|
| 什么时候结婚? | 当我结婚的时候,我就结婚了 |
| 工资多少? | 你见过凌晨四点的办公室吗? |
| 买房了吗? | 当我买得起的时候,我就买了 |
| 有对象了吗? | 当你谈恋爱时,你就在恋爱 |
| 什么时候生二胎? | 时机到了,孩子就来了 |
