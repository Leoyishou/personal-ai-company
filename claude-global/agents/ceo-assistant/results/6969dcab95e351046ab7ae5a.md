## 一、什么是 Deeper Search

Deeper Search（也称为 Deep Research）是一类新兴的 AI 研究代理框架，其核心理念是让大语言模型（LLM）像真正的研究员一样自主进行深度调研。与传统的单次搜索不同，这类系统能够：

1. **迭代式搜索**：根据初始问题自动生成多轮搜索查询，层层递进深入挖掘
2. **自主推理**：在搜索过程中不断评估信息质量，决定何时继续搜索、何时停止
3. **信息综合**：从多个来源抓取网页内容，进行去重、验证和结构化整理
4. **报告生成**：最终输出完整的研究报告，包含来源引用和推理过程

这一概念由 OpenAI 于 2025 年初随 ChatGPT Pro（$200/月）推出，随后迅速被开源社区复现和扩展。

## 二、主流开源框架

| 框架名 | 来源 | 特点 |
|--------|------|------|
| **Open Deep Research** | Hugging Face | 官方开源实现，基于 smolagents 库，支持任意 LLM |
| **DeepSearcher** | Zilliz/Milvus | 本地运行，结合向量数据库进行私有数据搜索 |
| **Auto-Deep-Research** | HKUDS (港大) | 支持多 LLM，按量付费替代 $200 订阅 |
| **Deep-Research** | dzhng | 极简实现，Firecrawl + o3-mini 推理 |
| **DeepResearch** | Jina AI | Gemini Flash + 多搜索引擎 |
| **Tongyi DeepResearch** | 阿里通义 | 首个对标 OpenAI 的全开源实现 |

**推荐**：dzhng/deep-research（代码精简，快速上手）

1. **用户痛点深度挖掘** - 搜索笔记 -> 分析评论区吐槽 -> 生成痛点报告
2. **竞品内容策略分析** - 分析竞品爆款特征、发布规律
3. **内容灵感挖掘与验证** - 提取高互动话题和热门标签
4. **用户画像构建** - 基于帖子分析目标人群特征
5. **舆情监控与趋势发现** - 情感分析 + 预警负面舆情
