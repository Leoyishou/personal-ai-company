# /build-fix - 构建失败修复

当构建失败时，按以下流程排查修复。

## 第一步：读取错误

1. 完整阅读错误信息
2. 识别错误类型：
   - 语法错误
   - 类型错误
   - 依赖缺失
   - 配置问题

## 第二步：定位问题

根据错误信息定位：
- 文件路径
- 行号
- 相关模块

## 第三步：分析原因

常见原因：
- 拼写错误
- 导入路径错误
- 类型不匹配
- 缺少依赖
- 版本不兼容

## 第四步：修复

1. 做最小改动修复问题
2. 重新运行构建
3. 如果仍失败，回到第一步

## 第五步：验证

- 构建成功
- 测试通过
- 功能正常

## 注意

- 不要盲目修改，先理解错误
- 一次只修一个问题
- 修复后立即验证
