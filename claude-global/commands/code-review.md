# /code-review - 代码审查

对指定代码进行全面审查。

## 审查清单

### 1. 正确性
- [ ] 逻辑是否正确？
- [ ] 边界条件是否处理？
- [ ] 错误处理是否完善？

### 2. 安全性
- [ ] 是否有注入风险（SQL、XSS、命令注入）？
- [ ] 敏感信息是否暴露？
- [ ] 权限检查是否到位？

### 3. 性能
- [ ] 是否有 N+1 查询？
- [ ] 是否有不必要的循环？
- [ ] 大数据量时是否会有问题？

### 4. 可维护性
- [ ] 命名是否清晰？
- [ ] 是否符合项目规范？
- [ ] 是否有过度抽象？

### 5. 测试
- [ ] 测试覆盖是否充分？
- [ ] 边界情况是否测试？

## 输出格式

```
## 审查结果

### 问题 (Critical/Warning/Info)

1. [Critical] 文件:行号 - 问题描述
   建议：修复方案

### 亮点

- 做得好的地方

### 总结

整体评价和优先修复建议
```
